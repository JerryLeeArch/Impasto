# Impasto

Impasto is a local-first taste log for music, images, and changing opinions.

## How to Run Impasto

macOS:

- Double-click `openImpasto.command`

Windows:

- Double-click `openImpasto.cmd`

On first launch, the Windows launcher downloads the required Node.js runtime
into `.runtime`, verifies it, installs dependencies, and opens Impasto
automatically. No global Node.js install or admin setup is required.

If macOS blocks the first launch, open `System Settings > Privacy & Security`, click `Open Anyway`, then launch it again.

On Windows, no extra permission step is usually needed.
